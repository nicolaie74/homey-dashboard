Koble til Homey

Du logger inn med Homey-kontoen din. Dashboardet trenger en egen API-klient fra Homey Developer Tools (gratis). Klientnøklene lagres bare i denne nettleseren.

Slik lager du API-klienten
  1. Gå til tools.developer.homey.app → API Clients og logg inn med Homey-kontoen.
  2. Lag en ny klient. Lim inn omdirigerings-URL-en over som Callback/Redirect URL.
  3. Gi den tilgang til enheter (se og styre), soner, Flows (se og starte) og vær.
  4. Kopier Client ID og Client Secret hit, og trykk «Logg inn med Homey».
